# cqy_toolbox
cqy 的工具集合

# 工具格式要求
- 功能描述
- 输入参数详细介绍
- 输出参数详细介绍
- 异常情况介绍
- 注意事项
- 示例


# 目录说明
- [scripts](./scripts/) 中按编程语言区分子文件夹，当前有 mlu 工具和 python 工具
  - [python 工具](./scripts/python/)的依赖项同一放在 [requirements.yaml](./scripts/python/requirements.yaml) 中，
    示例可以从 templates 中获取，python 工具都是直接可以运行的工具。
- [templates](./templates/) 中放开放式的结构化的示例
